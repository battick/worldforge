# 2026-09-30

## 编年（再续）：右栏并进同一张纸、纪元色段铺满墙沿、字体收一档

作者原话：

> 「最右侧的编年卡片有点不符合这个风格，包括上方的，和总体的布局都有些割裂」
> 「卡片和整体布局的比例中字体过大，有种头重脚轻的，要适量留白」

### ① 右栏不再是一张浮在外面的卡

`ChronicleView` 外面套了一层 `.chron-sheet`：左 `.chron-main`（展墙）/ 右 `.chron-side`（注记栏）。
原来是两个并排的块，右栏用的是通用「卡片」（圆角 + 描边 + 投影），浮在展墙旁边像个外挂控件。
现在：

- 两半**同一个底色**（`--bg-soft` 交给 `.chron-sheet`，`.chron-card` 改 `transparent`）、
  **`align-items: stretch` 同高** —— 栏线因此通到底，不会出现「右栏只有上面一小块、下面全是空的」；
- 注记栏里**一条边框/圆角/投影都不要**（`.chron-note`），分小节靠 `.chron-note-head`
  （11.5px、`letter-spacing: .08em`、`--text-dim`）的层级；两个数（已排进轴 / 还没排进）改成
  `.chron-stats`（宋体 19px + 11.5px 标签），不再是「卡片里的一行 kv」；
- 池子从「一圈圆角列表项」改成**平铺的行 + 发丝线分隔**（只覆盖 `.chron-side .tl-pool-*`；
  `.tl-pool-*` 是两支视图共用的，**基类一个字没动**），hover 只把标题染成主色；
- 窄屏（≤1080px）才塌成一栏，栏线改到上头。

### ② 纪元带的色段**铺满**墙沿

原来是「首尾**条目中心**」拉一条线 —— 那是上一版卡片会互相压着时的防重叠办法。现在卡片绝不重叠、
一张挨着一张，按边缘取值反而正好把墙沿分段铺满。新的 `eraSpans`：

- 每段 = `[这一纪元第一张卡的左沿, 最后一张卡的右沿]`，再按**相邻两段之间的中点**分界
  （那段空白一个事件都没有，归谁都不算错）；
- 第一段 `x1 = 0`、最后一段 `x2 = W` —— **整条轴被分完，颜色换一次就是换了一个纪元**；
- 万一纪元交错出现（`A…B…A`），后面那段只许落在前面那段之后（宁可让出一小截，也不许叠）；
- 色线 `margin-bottom: -1px` **压在墙沿那根发丝线上**，而 `.chron-era` 要 `z-index: 2`
  —— 不然会被后画的 `.chron-wall`（`position: relative`）盖住；
- 纪元名 17 → 15px、`BAND_H` 46 → 40（它是墙头题字，不该比卡片标题还抢眼）。

### 这一轮踩到 / 认清的

- **`Page.captureScreenshot` 不带 `captureBeyondViewport: true` 会画出不在 DOM 里的色块**：
  页头那颗「编年」chip（圆角 + 主色底）被当成另一个图层、以错位坐标合成进整页截图 ——
  图上多出一块蓝块压着说明文字，而 `elementsFromPoint` 在那个点**谁也找不到**（真是合成器画的）。
  上一轮在 `clip` 那条路上已经吃过一次，这次在整页路上又吃了一次：**`shot()` 也一律带上这个参数**。
- **看图工具会按内容去重**：同一张整页图看第二遍不重画（"Image unchanged"），
  于是「改完再看一眼」这件事在整页图上做不到。解法是**裁一块新的出来看** →
  新增 `.dev/crop.py`（Pillow，装在隔离 venv 里），按截图像素裁 + 放大，用来评宋体与留白。
- **别拿视口坐标跟宽度比**：新写的 e2e 断言「纪元色段铺满整条轴」时报了 `0→2843 / 轴宽 2578`，
  看着像 bug —— 其实 2843 是**视口坐标**，2578 是**宽度**，差的是画布左沿（左边有侧栏）。
  改成比 `canvas.left` / `canvas.right` 之后一次过。
- **模板字符串里不许出现反引号**：往 e2e 的 `evaluate(\`...\`)` 里写注释时写了
  `` `getBoundingClientRect` ``，反引号把模板字符串提前收尾 → `SyntaxError: missing ) after argument list`。
  这类错 `node --check` 一秒就能抓，改完先 check 再跑。
