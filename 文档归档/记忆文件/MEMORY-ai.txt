# WorldForge AI 契约与循环须知（速查·第三册）

> 分工见 `MEMORY.md` 卷首。本册 = 原 §3/§4/§5：**改 AI 解析、agent 循环、任务队列时先读这份**
> （连同 `CASES.md` 的同号小节）。

## 3. AI 解析与工具契约

- **协议解析绝不能静默丢动作**（`plan` 写成对象 / 键名换 `steps` / 参数塞 `arguments` / `plan` 被序列化 / say 与 plan
  并列 / 根级直接给动作 / `CreateEntry` 写法）→ 救不回就打 `protocolBroken` 如实说。工具名查找走 `findTool()`。
- **有损救援不许排在无损前面**（收尾括号 → 逐 token 修结构 → 才切尾，切尾只在 `closeTruncated` 报 `truncated` 时）。
- **「只往末尾补括号」救不了「中间少一个」** → 逐 token 状态机：在「该写键名」处撞见 `{` 就补 `}` 收掉当前层、
  再拿同一 token 到外层重试；补前先撤掉紧挨的尾逗号。
- **修复必须守门**（`looseJson` 三条：像 JSON / 改动数 > `min(64, 字符数/8)` → `undefined` / 修完能 parse）。
- **修好了也要说，且与「真废了」分开**：`repaired`（中性）/`retried`/`gaveUp`（警示）。**修复 ≠ 放过**（照旧进审查队列）。
- **`AgentTool.args` 是三处共用的一份契约**：`normalizeArgs()` 折别名回规范名（别名是**移动**不是复制）/ `renderToolList()`
  必须把它印进清单（`｜参数：entry（必填）`）/ `unit-args.mjs` 静态自检。
- **归一第二遍不许抢本工具自己的另一个规范名**（`update_entry` 的 `title` 是「改成什么标题」）。
- **缺参数的报错必须「能照着重写」**：说清**缺哪个 / 认哪些 / 你给的是什么**；**「值写错」也算「调用写错」**
  （分类名对不上要带上现有分类清单）。
- **提示词返回形状 ↔ `asArray` 的 `LIST_KEYS` 是一份契约，改一边必须改另一边**（漏登记 → 整份结果静默丢空）；
  兜底：整份只有**一个数组字段**就认它，多个不猜。
- **「读不懂」不许冒充「没问题」**：`hasListShape()` 分出 `{"issues": []}`（真结论）与 `{"note":"…"}`（答非所问 → **报错**）。
  **凡「空结果」会被界面译成一句安抚话的地方，都要先确认那个空是真结论。**
- **全角只在结构判断处归一**（`｛｝［］：`）；引号全角变体**不认**。

## 4. agent 循环（`state/useAgent.ts` + `ai/agent/`）

- **系统提示词每轮重新构建**；会话**整段覆盖保存**（`saveThread`）。写操作后打 `dirtyRef`、下个动作前 `refreshLive()`。
- **`say` 承诺动手却把 `plan` 留空 = 这件事就此结束** → 提示词明写「打算用工具就写进 plan」；整轮不合格式补一轮
  `agent.sys.repair`（限一次）。**界面处置措辞在落库那一刻定死**（`retried`/`gaveUp`）。
- **`plan: []` ≠ 做完了** → 有显式 `done`；**清单没清空不许收工**（追问 2 次 → 摆出「还剩几条」收尾）；轮数上限 20。
  **「待办清单」与「动作」同一轮给是常态**（判据 `todosGiven`）。
- **「查不到就问，别换个关键词接着查」**（零命中=信息不够）。`ask_author` 是 **terminal**、**不受三档边界约束**。
- 护栏：`签名 = 工具+排序参数` 拦重复；`stalls` 累积失败/零命中/重复 → `STALL_NUDGE=2` 提醒、`STALL_STOP=4` 停下写
  `turn.stuck`。**签名去重只拦「成功过的那次」**；拦下时回执要**引出上一次的真实结果**；`worldRev` 写一次 +1。
- **「调用写错了」和「查不到」是两件事，四处都得分开**：失败回灌（`resultEmpty`/`resultBadCall` ← `ToolOutcome.badCall`）、
  护栏插话（`stuckNudge`/`badCallNudge`）、停下说明（`agent.err.stuck`/`stuckBadCall`）、对话短标记
  （`ChatTurn.stuck: 'empty'|'badCall'`）。
- **跨轮记忆**：每轮把**这次交代之前**的对话（最近 6 条、每条截 220 字）印进系统提示词；挑法是「不要**系统轮**、
  不要一句话没说的轮、从末尾往前取」，标题必须点破「这是语境不是要你重做」。取语境**谁新用谁**。
- **「作业指导」要写进系统提示词**（别指望它自己推）：`agent.sys.complete` 写死「先 `read_entry` 读正文（一轮多个动作）
  → 拿专有名字去库里对（含别名、**含审查队列待批的**）→ 只提真缺且当独立实体用的 → 一次给齐字段 + 正文骨架 → 收尾报数」，
  且不许把「已提交审查」说成「已经建好了」。
- **工具说明只能提真实存在的工具**；界面显示**人话标签**（`toolLabel()` ← `TOOL_LABEL`）。
- **AI「锦上添花」必须能静默降级**（不弹错、不挡主流程），且**别走 `useAIAction`**（会占 loading/stream）。
- **提示泡只负责「填」，不替作者发**：`studio.suggest.*` 点一下**追加一行**进输入框并聚焦；`ob-suggest` 是**候选答案**、
  语义不同、那边仍覆盖且点一下就发。
- **「下一步建议」只在「把话交回给作者」的轮次算数**（`plan` 为空**或全 terminal**，判断写在循环里）；界面只让
  **最后一条** AI 轮的按钮可点；**模型自己给了建议的那一轮，别再花一次请求替它出题**。
- **AI 审计类任务必须自带账本**：`buildLedger()` 按「还该不该重看」分三组塞进提示词 + 明写「换个说法也算重复」；
  `splitDuplicates()` 入库前再拦一道、拦下的**如实报**。判重**只认字面**。
  **「把真问题当重复悄悄丢掉」比「多显示一条重复」严重得多：宁可漏，不可错杀。**
- **「还该不该重看」用时间戳判**（`touchedSince()` = `entry.updatedAt > issue.createdAt`）；改过→放行并写明变化。
- **送进模型要有「总预算」**（按条目数平分、下限 200 字），**界面上写的数字必须来自真正生效的那一份**。
- **已判定（已处理/已忽略）的问题别继续占待办**。空态分两种。

## 5. AI 任务 / 队列 / 批量

- **AI 任务状态别住在页面里** → `state/aiTasks.ts` 模块级任务表 + `useAITask(key, navKey)`；agent 运行器挂 `Shell`。
  **结果与勾选一起搬**（`{items, picked}`）；同页语义不同的调用用**不同任务键**；分批任务包在**一次** run 里；
  `getSnapshot` 返回稳定引用，派生集合返回**字符串**而非 Set。
- **`run(fn)` 只负责跑、不代存结果**：要「跑完还留着看」的，成功分支 `setResult(...)`、失败分支 `setResult(null)`。
- **能中止的长任务把 `AbortSignal` 一路传下去**（循环里每轮查 `ctx.signal?.aborted`）。
- **「连点好几下」和「同一任务不叠着跑」是两件相反的事**：要排队走 `state/jobQueue.ts`（串行、可撤单、可重试）。
  **队列是通用设施、不许认识业务**；**拦截做在入队之前**；排进队列的活儿带 `navKey`。
- **做判断读队列模块本身（`hasLiveJob` 直读内部表），显示才读 React 快照**。
- **入队前按下快照，写回时用最新那份**（`liveStore` ref）；落库前**再对一次账**。
- **撤单要连着「一个请求都不发」一起验**（假上游 `byBranch` 计数盯）。
- **批量打磨要比单条扩写更克制**（提示词第一条纪律是「能不动就不动」；`changes` 为空的**不入队**但记 skipped 如实报）。
  **「无需改动」是结论、「答非所问」是没读懂，必须分开**（无 `content` 也无 `summary` → 抛 `ai.err.shapeMismatch`）。
  同批提议共用 `ReviewItem.batchId`；`startBatch` 先跳过已有待审 `update-entry` 的目标。
- **一次产很多份提议先按「目标」归并再发一次请求**（`consistencyFixMany` + `consistencyFixItem`），**每条修订只占队列一个位置**。
  `fixTargetOf()` 取「第一个**还在库里**的相关条目」；施工图用**本次批号**排除自己刚推出去的提议、**跑完置回 null**。
- **一批活儿交给队列后，界面上别再存一份它的状态**（进度要现算）。
- **「一次 AI 排版」是一条提议、不是 N 条**（`ReviewItem.layoutDraft`；拆开会丢掉「这几条之间的先后」）。采纳时逐条走
  `setEntryTime`、**不给它补汇总日志**；**AI 只写位置，不碰作者写的时间文字**（`from`/`to` 一字不动；
  锁定条目被挪位置时由 `runTimelineLayout` 顺带重写 `from`，见 2026-10-01 日志）。
- **agent 的写操作一律产出「提议」进审查队列、不许直接落库**（三档边界只管「动作要不要先问」，**管不到产出要不要审**）。
  撤销提议要**连带撤回**依赖它的关系提议；采纳关系提议前两端必须都已落地；`acceptReview` 的 follow 用**双向匹配**。
